Meeting 助手 V3.1.1 建置與安全修正報告

修正原因
- Chrome Console 顯示 Content Security Policy 阻擋：
  https://vercel.com/api/blob/?pathname=...
- 既有 `connect-src` 只允許本站、Blob 儲存網域、Gemini 與 Google APIs，未允許 Vercel Blob Client Upload 的控制端點。

修正內容
- `vercel.json` 的 Content-Security-Policy → connect-src 新增 `https://vercel.com`。
- 保留 `https://*.blob.vercel-storage.com`，讓瀏覽器將音檔直接傳至 Private Blob。
- 專案版本更新為 3.1.1。

檢查結果
- vercel.json JSON 語法：通過
- package.json JSON 語法：通過
- npm test：8/8 通過
- npm run build：未在此環境重跑（內部 npm registry 無 @vercel/blob 2.6.1）；原 V3.1.0 已完成建置，本次僅修改 vercel.json CSP 與版本文字

部署注意
1. 將新版 `vercel.json` 上傳 GitHub 根目錄並覆蓋舊檔。
2. 等待 Vercel 自動部署 Production。
3. 開啟正式網址後按 Ctrl+F5。
4. 用短音檔測試。
