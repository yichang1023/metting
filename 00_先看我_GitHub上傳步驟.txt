Meeting 助手 V3.0｜GitHub 上傳步驟

1. 請先解壓縮 ZIP。
2. 到 GitHub 建立新的 Private Repository，名稱建議 meeting-assistant。
3. 建立 Repository 時，不要另外產生 README、.gitignore、License。
4. 進入空白 Repository，選 Add file → Upload files。
5. 把本資料夾「裡面的全部檔案與資料夾」拖入 GitHub。
6. 確認 api、lib、docs、tests、scripts 資料夾與 index.html、package.json、vercel.json 都有出現。
7. Commit message：Meeting Assistant V3.0 initial upload
8. 按 Commit changes。

重要：
- 不要只上傳 ZIP；GitHub 不會替你解壓縮。
- 不要在任何檔案填入真實 Gemini API Key。
- 真實 Key 下一階段要填在 Vercel Environment Variables。
