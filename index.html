🔐 Vercel 後端連線

Gemini API Key 由 Vercel 後端的 Environment Variables 安全讀取，使用者不需要、也不應在本頁輸入 Gemini API Key。 下方是「網站存取碼」；當你在 Vercel 設定 APP_ACCESS_TOKEN 時才需要輸入。

勾選「記住」後，Vercel 後端會建立最長 30 天的 HttpOnly 安全 Cookie；瀏覽器 JavaScript 無法讀取 Cookie 內容，也不會把網站存取碼明文存進 localStorage。這只保留登入狀態，不會讓本機會議資料產生雲端同步。

🎙️ 語音辨識強化

中文姓名與專有名詞屬於較敏感的個人化資料，因此預設收合；只有主動點選後才會顯示內容。

🔐 顯示專有名詞、校正詞典與老師姓名
這些資料只儲存在目前瀏覽器的本機資料中，不會隨 Gemini API Key 傳送；開始分析時，只會把必要的辨識提示交給 AI。
📖 專有名詞詞庫
一行一個。填入實驗室成員姓名、老師姓名、常用術語。這些詞會直接告訴 AI「正確的字長這樣」，讓它在轉錄時優先選用。
🔤 自動校正詞典
格式：錯誤字=正確字，一行一組。分析完成後會自動把逐字稿裡的錯字全部換掉。
🧑‍🏫 老師姓名
一行一個。逐字稿的說話者只會顯示「老師」或「學生」；若 AI 仍吐出姓名，系統會用這份清單判斷角色。

🔍 上傳能力自我檢測

「最大能傳多大」取決於你的瀏覽器記憶體與 Google 的 CORS 設定，無法事先斷定。 按下按鈕會在你這台電腦上實測，並算出實際可用的上限。

🔐 Meeting 助手安全驗證

為了多一層安全性保護，請先輸入網站存取碼，驗證成功後才能使用錄音上傳與 AI 分析功能。
錄音檔較大怎麼辦？
若檔案大於 15MB，驗證後可到「上傳錄音」切換 🗜️ 先壓縮，再送 AI 分析。壓縮會在你的瀏覽器內完成，完成後可自動接續 AI 分析，不必重新選檔。
